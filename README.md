# MoodBoard - Your Daily Visual Diary

MoodBoard is an open-source project that allows users to create and manage a personal visual diary. With MoodBoard, you can capture and organize your daily moods, experiences, and inspirations through a visually-appealing interface.

## Key Features

- **Intuitive Mood Tracking**: Easily log your daily moods using a variety of visual cues and annotations.
- **Visual Diary**: Collect and curate your daily photos, sketches, and other visual content to build a personal diary.
- **Mood Analytics**: Gain insights into your emotional patterns and trends over time through comprehensive mood analytics.
- **Customizable Layouts**: Personalize your MoodBoard with a range of layout options and themes to suit your preferences.
- **Secure Data Storage**: Your diary entries and visual content are securely stored and accessible only by you.
- **Cross-Platform Availability**: Access your MoodBoard from any device, including mobile, tablet, and desktop.

## Getting Started

1. Clone the repository: `git clone https://github.com/your-username/MoodBoard.git`
2. Install the required dependencies: `pip install -r requirements.txt`
3. Run the application: `python app.py`
4. Open your web browser and navigate to `http://localhost:5000` to start using MoodBoard.
