# MoodBoard

A visually stunning, interactive daily mood tracking web app that helps users express and track their emotional wellbeing through colors, patterns, and animations. Users create beautiful abstract art pieces that represent their daily mood, which are assembled into a mesmerizing visual diary over time.

Key Features:
- Interactive mood canvas creation
- Color psychology-based mood mapping
- Daily streaks and achievements
- Monthly mood pattern visualization
- Social sharing capabilities

Tech Stack:
- HTML5 Canvas
- CSS3 Animations
- Vanilla JavaScript
- Local Storage for progress tracking
